# 播客逐字稿清洗与整理

将原始分段转换为可读但可追溯的逐字稿。核心标准：**不折损、顺序不变、轻编辑、风险显式、允许带风险归档**。

## 输出选择门（执行前必问）

在开始抓取、清洗、批量更新或归档之前，先检查用户是否已经明确输出载体。

- 若尚未明确，必须主动询问一次：`本次逐字稿希望输出为：A. 飞书文档；B. Markdown 文件；C. 两者都要？`
- 在用户选择前可读取输入并检查缺口，但不得创建飞书文档、写出最终 Markdown 或执行批量归档。
- 用户已明确选择时不重复询问。
- 记录 `output_targets`，值只能为 `lark_doc`、`markdown` 或二者组成的数组；批量单集继承同一选择。

### 飞书文档

- 读取运行环境中最新的飞书在线文档 Skill，再执行创建或更新。
- 已存在同一 `episode_id` 的文档时原地更新，禁止生成重复文档。
- 交付文档链接；本地 Markdown 可以作为中间渲染源，但不额外交付。

### Markdown 文件

- 生成 `transcript.readable.md`；批量任务同时生成周报或索引 Markdown。
- 使用可移植相对链接，不写内部 token、账号信息或运行环境绝对路径。
- 不创建或修改飞书文档；最终交付 `.md` 文件。

### 两者都要

- 使用同一份权威阅读内容分别渲染 Markdown 与飞书文档，不得各自改写。
- 两个输出的标题、风险状态、阶段标题、说话人顺序和正文必须一致。
- 分别验证并交付文档链接和 Markdown 文件；任一分支失败时明确报告部分完成状态。

## 输入

同一单集目录中读取：

- `metadata.json`：标题、节目、发布日期、节目页和音频时长。
- `transcript/segments.raw.json`：起止时间、speaker、文本和可选置信度；不得覆盖。
- `transcript/transcript.meta.json`：来源、ASR 时长与上游状态。
- `transcript/translations.zh.json`：英文原文逐片段对应的中文译文；按相同起止时间关联，不能覆盖原文。
- `shownotes.raw.txt`：只提取明确章节时间点，不拼入正文。

缺少 `metadata.json` 或 `segments.raw.json` 时停止，不从简介重建逐字稿。

单集目录默认命名为 `YYYY-MM-DD_节目名_简短标题`；完整 `episode_id` 只保存在元数据中，不用作默认目录名。同名冲突时才追加 `episode_id` 前 6 位。

## 三层产物

1. **证据层**：原始分段和元信息，保持原样。
2. **阅读层**：`topic-digest.json`（议题提要结构）、`transcript.readable.md` 和周报 HTML。
3. **结构层**：`dialogue.readable.json`、`quality-report.json`。

议题提要是完整逐字稿前的快速阅读层，不替代逐字稿，也不改变逐字稿时间顺序。正式生成前读取 [`references/topic-digest.md`](references/topic-digest.md)。

## 工作流

1. 执行“输出选择门”，确认 `lark_doc`、`markdown` 或两者；未选择时先询问。
2. 校验时间戳、空文本、时长覆盖、speaker 分布、长静默和置信度。
3. 先判定 `single` / `multi` / `auto` 说话人模式：单人节目统一显示为 `说话人1`；多人节目按原始稳定声纹首次出现顺序连续编号为 `说话人1`、`说话人2`、`说话人3`……，人数不设上限；缺失标签保留未确定，不推断身份。正式处理前读取 [`references/speaker-modes.md`](references/speaker-modes.md)。
4. 合并连续同说话人碎片：默认间隔不超过 3 秒，合并后不超过 420 字。
5. 仅规范空白、标点、完全相邻重复和对话块句末标点，不重写措辞。
6. 将可靠章节按时间插入正文；没有章节时每 15 分钟建立“自动分段”。
7. 判定逐字稿语言。英文或英文为主的访谈必须读取 [`references/bilingual-transcript.md`](references/bilingual-transcript.md)，为每个英文片段生成忠实中文译文，并保存到 `translations.zh.json`；阅读版中文译文在上、英文原文在下。中文访谈不生成空的英文原文区块。
8. 完整阅读逐字稿后生成 `topic-digest.json`：默认 3–8 个顶层议题，每个 1–6 个二级要点，最多两层；所有 bullet 默认使用中文，每项附逐字稿起止时间，保留数字、案例、术语、对比和不确定性，不添加外部事实或编辑判断。
9. 生成结构化对话、质量报告和唯一权威阅读内容；议题提要置于元信息与完整逐字稿之间。
10. 按 `output_targets` 生成飞书文档、Markdown 或两者；风险只标记，不阻止生成。
11. 分别回读所选输出并交付。

```bash
python3 <skill-dir>/scripts/clean_transcript.py <episode-dir>
```

## 编辑边界

允许：

- 统一空白和中英文标点形态。
- 合并同一说话人的连续短片段。
- 删除文本完全相同且时间重叠/紧邻的 ASR 重复。
- 补完整对话块的句末标点。

需要直接证据才能修正：

- 人名、公司名、产品名、缩写和专业术语。
- 金额、年份、比例、版本号等数字。
- 同音错字和 speaker 瞬时跳变。

禁止：

- 优化观点、事实纠错、补写内容、删除限定词。
- 将 Shownotes、简介或评论混入正文。
- 猜测说话人真实身份。

## 风险级别

- `normal`：未发现显著机器风险。
- `notice`：自动章节、少量低置信或少量长静默。
- `review_recommended`：覆盖不足、speaker 缺失、置信度不可用或长静默较多。
- `high_risk`：时间戳逆序、大段缺失、身份冲突或结构只能部分解析。

所有级别均允许生成，阅读稿头部必须显示机器转写声明、风险级别和原因。

详细阈值见 [`references/format-and-risk.md`](references/format-and-risk.md)。

## 阅读版结构

```markdown
# YYYY-MM-DD｜播客名｜单集标题

> ASR 机器转写，未经人工校对。
> 质量状态：注意。使用自动分段。
> 说话人编号仅表示本文内不同声纹，不代表真实身份。

## 逐字稿

## 00:15:00｜阶段标题

**说话人2** · 00:15:04

中文访谈：发言正文。

英文访谈：对应的中文译文。

> **英文原文**
> The original English statement.
```

不生成独立章节导航，不为每段发言使用标题。英文访谈每个发言块严格“中文译文在上、英文原文在下”，时间戳和说话人只显示一次；完整规则见 [`references/bilingual-transcript.md`](references/bilingual-transcript.md)。`## 议题提要` 最多两层 bullet，默认全部使用中文，每个议题和二级要点都附时间范围；顶层写议题与核心判断，二级保留数字、案例、对比、术语和不确定性。议题提要不替代下方完整逐字稿，详细规则见 [`references/topic-digest.md`](references/topic-digest.md)。

## 输出分支实现

### 飞书文档

仅当 `output_targets` 包含 `lark_doc` 时执行：读取运行环境中最新的飞书在线文档 Skill；已有同一 `episode_id` 文档时原地更新，否则按用户指定目录创建；写后回读并交付文档链接。未选择飞书时禁止创建、修改或归档飞书文档。

### Markdown 文件

仅当 `output_targets` 包含 `markdown` 时执行：写入 `transcript.readable.md`，批量任务同时生成索引或周报 Markdown；文件夹使用 `YYYY-MM-DD_节目名_简短标题`；只使用相对路径或公开链接；回读验证后交付 `.md` 文件。

### 两者都要

从同一权威阅读内容分别渲染，不得在任一端另行润色；核对标题、风险状态、阶段标题、说话人顺序和正文一致后，分别交付飞书链接与 Markdown 文件。

## 周报 HTML

```bash
python3 <skill-dir>/scripts/render_html_reader.py <manifest.json> --output <report.html>
```

公开环境的逐字稿链接优先使用 `transcript_url`；企业环境可自行映射其他文档 URL 字段。链接必须是 HTTP/HTTPS，不接受本地绝对路径。

## 完成检查

- 用户输出选择已记录，只生成所选载体。
- 原始证据未被改写。
- 阅读版时间顺序、首尾覆盖与输入一致。
- 单人节目正文只出现 `说话人1`；多人节目编号从 1 连续递增且不限制人数；缺失标签不被猜测填充。
- `speaker_mode_resolved`、原始/归一人数、映射表和风险代码可由输入复算。
- 议题提要最多两层、所有 bullet 默认中文、每项时间证据有效，且完整逐字稿仍按时间保留。
- 英文访谈每个发言块均保留英文原文；有译文时中文在上、英文在下，缺译时标记风险而不伪造；中文访谈不出现空的英文原文区块。
- `translation_required`、翻译覆盖率和缺译数量可由 `dialogue.readable.json` 复算。
- 风险已标记，而非阻止产物。
- 质量报告中的数字可复算。
- Markdown 输出使用可读路径和可访问相对链接；飞书输出原地更新并回读；两者并行时内容一致。
- 输出不含凭据、内部路径或个人信息。
